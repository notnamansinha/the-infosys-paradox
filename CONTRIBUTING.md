# Contributing

This repository archives a completed academic research project. The analysis pipeline,
charts, and documentation are published for transparency and reproducibility.

## Reporting issues

Open an issue if you find:

- A factual error in the dataset or documentation.
- A broken script path or missing dependency.
- A file that should have been excluded from the public repository.

## Pull requests

Pull requests that correct data errors, fix script portability, or improve
documentation clarity are welcome. Changes to the analytical conclusions
require supporting evidence cited in the pull request description.

## Code style

- Python scripts follow PEP 8.
- Markdown files use ATX headings (`#`), one sentence per line where practical,
  and relative links to other repository files.
